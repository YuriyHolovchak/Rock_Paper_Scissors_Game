# Rock Paper Scissors - freeCodeCamp project, completed by Yuriy Holovchak

Initial Note from freeCodeCamp: This is the boilerplate for the Rock Paper Scissors project. Instructions for building your project can be found at https://www.freecodecamp.org/learn/machine-learning-with-python/machine-learning-with-python-projects/rock-paper-scissors

# Implementation:
* The player is implemented in the RPS.py file and contains strategies to beat all four bots created by freeCodeCamp in RPS_game.py file.
* The RPS_game.py file was untouched other than the addition of comments inside each function implementation to explain bot strategies.
* The main.py file is used to test how the player plays against the different types of bots during development.
* The test_module.py file contains the final automated challenge tests.
